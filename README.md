# NutriVibe

AI-Powered Health & Nutrition Tracking Platform

## Project Overview

NutriVibe is a full-stack health and nutrition platform designed to help users monitor their nutrition, fitness, and health-related metrics.

## Tech Stack

- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Machine Learning: Python, FastAPI
- ML Integration: Node.js ↔ FastAPI
